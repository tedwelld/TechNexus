# Axentra Tech Solutions

Marketing website for Axentra Tech Solutions.

## Pages

- `/` Home
- `/services` Web & software services
- `/services/it` Managed IT solutions
- `/work` Case studies
- `/about` Mission & team
- `/pricing` Packages & comparison
- `/stack` Tech arsenal
- `/process` Delivery process
- `/contact` Inquiry form

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js App Router, TypeScript, Tailwind CSS v4.
